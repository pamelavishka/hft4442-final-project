# Go Gator Resort & Spa

Requires Node.js 22.13 or newer.

```sh
npm ci
npm run dev
```

Validation:

```sh
npx tsc --noEmit
node tests/concierge.mjs
npm run build
```

No API key is required. See README.md for voice support and course limitations. The docs directory contains the two supplied course documents and website preview.
